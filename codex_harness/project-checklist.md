# 법률 MCP 하네스 점검 체크리스트

## 범위 정책

- [ ] 일반 사용자, 기업, 전문직 사용자를 대상으로 한다.
- [ ] 학교, 교육기관, 수업, 과제, 성적 평가 맥락을 차단한다.
- [ ] 법률 자문이 아니라 정보 제공과 문서 초안 작성 보조로 표현한다.
- [ ] 최종 판단, 승소 보장, 위법 단정을 하지 않는다.
- [ ] 고위험 사안은 전문가 검토 필요로 표시한다.

## API와 워크플로

- [ ] `POST /api/legal-research`가 법률 리서치 결과를 반환한다.
- [ ] `POST /api/contract-review`가 계약서 위험 검토 결과를 반환한다.
- [ ] `POST /api/document-draft`가 초안 전용 문서 결과를 반환한다.
- [ ] 각 엔드포인트는 Zod 입력 검증을 수행한다.
- [ ] 교육 맥락 요청은 422로 차단한다.
- [ ] 모든 성공 응답은 `policy.requiresExpertReview`를 포함한다.

## 안전 필터

- [ ] 단정 표현을 탐지한다.
- [ ] 승소 보장 표현을 완화한다.
- [ ] 위법 단정 표현을 완화한다.
- [ ] 형사책임 단정 표현을 완화한다.
- [ ] “변호사 없이 가능” 유형 표현을 고위험으로 처리한다.

## 출처와 인용

- [ ] 법령 근거는 법령명과 조문번호를 포함한다.
- [ ] 판례 근거는 사건번호 또는 선고일을 포함한다.
- [ ] 출처가 부족하면 `출처 확인 필요` 또는 `수동 확인 필요`를 표시한다.
- [ ] 근거가 부족한 경우 단정적 분석을 막는다.

## 제공자 연동

- [ ] `LEGAL_PROVIDER=mock`에서 결정론적 모의 결과를 반환한다.
- [ ] `LEGAL_PROVIDER=korean-law`에서 `LAW_OC` 누락 시 워크플로가 중단되지 않는다.
- [ ] 실제 `korean-law-mcp` CLI 호출 형식을 검증한다.
- [ ] 실제 제공자 실패 시 `검색 실패`, `수동 확인 필요`를 반환한다.

## 프론트엔드

- [ ] 법률 질문, 계약서 검토, 문서 초안 탭을 제공한다.
- [ ] textarea, 실행 버튼, 로딩 상태, 오류 메시지를 제공한다.
- [ ] JSON 원문 대신 리포트 카드로 결과를 표시한다.
- [ ] 전문가 검토 필요 여부를 눈에 띄게 표시한다.
- [ ] 문서 생성 결과는 초안으로 표시한다.
- [ ] 사용자 노출 문구는 한국어 중심이다.

## 검증 명령
